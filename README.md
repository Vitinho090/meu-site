# Investidor do Zero — Método ROTA™

Landing page desenvolvida para apresentar a proposta do método de educação financeira e estratégia de investimento.

## Visão geral

Este projeto é uma landing page em HTML estático, com foco em:

- atrair atenção para o tema de educação financeira
- explicar a proposta do Método ROTA™
- conduzir o visitante para o quiz e para a oferta
- apresentar uma experiência responsiva e clara

## Estrutura

- `index.html` — página principal
- `.gitignore` — ignora arquivos locais do editor

## Publicação

A página está publicada no GitHub Pages:

- https://vitinho090.github.io/meu-site/

## Tecnologias

- HTML5
- CSS3
- JavaScript vanilla

## Observação

A página contém elementos educacionais e não substitui orientação financeira individual. O conteúdo foi desenhado para apresentar uma proposta de aprendizagem e estratégia, e não para garantir rentabilidade ou resultados.
